# Подложка карты

Сюда нужно положить картинку игровой карты архипелага под именем **`base.png`**
(годятся также `base.jpg`, `base.jpeg`, `base.webp` — берётся первый найденный).

Подходит чистая карта без подписей округов и без цветной заливки: приложение
само рисует поверх неё маркеры округов и красит их в цвет победившей партии.

Требований к размеру нет — пропорции читаются из самого файла, и карта
вписывается в экран целиком. Разумный ориентир: ширина 2000 px и больше,
иначе при экспорте в PNG подложка будет мылить.

Файл в репозиторий не коммитится: это игровой материал, а не код. Пока его
нет, экран карты показывает серую заглушку — маркеры при этом расставлены и
работают, приложение не ломается.

Координаты маркеров лежат в файле проекта (`districts` → `x`, `y`, доли от
размера картинки) и в `parlament/district_seed.py`. Если маркер стоит не на
своём месте, поправить можно там, не трогая остальной код.
